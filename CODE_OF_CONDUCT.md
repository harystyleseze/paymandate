# Code of Conduct

PayMandate follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, be constructive, assume good faith, no harassment of any kind. Disagreements about code are welcome; disrespect toward people is not.

Reports: open a private report to the maintainers (contact in README) or, for conduct within a GrantFox campaign, use GrantFox's flagging process. Maintainers will acknowledge reports within 48 hours.

Enforcement: warning → temporary exclusion from the project → permanent ban, at maintainer discretion, with reasons stated.
